# Ответы на вопросы к зачёту

**Модуль 2.** Тактическая и тактико-специальная подготовка.
**Разделы:** 2.1, 2.3, 2.4, 2.5, 2.6, 2.7, ТСП.

Ответы подготовлены на основе действующих уставных и нормативных документов
Вооружённых Сил Российской Федерации:

- Боевой устав Сухопутных войск, часть III «Взвод, отделение, танк»
  (введён в действие приказом главнокомандующего Сухопутными войсками 2011 г.).
- Боевой устав Сухопутных войск, часть II «Батальон, рота».
- Устав внутренней службы Вооружённых Сил Российской Федерации
  (утв. Указом Президента РФ от 10.11.2007 № 1495).
- Федеральный закон от 31.05.1996 № 61-ФЗ «Об обороне».
- Военная доктрина Российской Федерации
  (утв. Президентом РФ 25.12.2014 № Пр-2976).
- Наставление по обеспечению боевых действий Сухопутных войск.

Полный список ответов — в файле [`otvety.md`](./otvety.md).
